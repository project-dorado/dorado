## Phase B — Functional runtime ✅ (with caveats)

### B.1 Real X11 launch (Xvfb)
`dotnet Dorado.Desktop.dll` launched under `xvfb-run` (1600×900×24), stayed alive
for the full 45 s window, and logged **no exceptions** — only the expected
`X connection ... broken` on teardown kill. (`DISPLAY` is empty in this
environment; a virtual display is required.)

### B.2 Real library scan (`test-media/`)
`MediaLibraryService.ScanDirectoryAsync` over
`/home/john/Projects/project-dorado/test-media`:

```
tracks=5  albums=2  artists=2
Epic Win Burlesque ... 01 Da Doo   | Unknown Artist | Unknown Album | 02:11
Epic Win Burlesque ... 02 Dentist! | Unknown Artist | Unknown Album | 03:05

Scary and Naked | Schaffer the Darklord | Pumpkin + Scary and Naked | 03:16
```
- The 3 WAVs carry no tags → folder-derived titles and `Unknown Artist/Album`
  (reasonable fallback; see Finding M-4).
- `video.mp4` is correctly excluded from the music scan.

### B.3 Real audio path
```
engine.IsAvailable (pre-load)      = False   # lazy init by design
PlayTrackAsync                     = completed, State=Playing, engine.HasActiveSource=True
coordinator.IsSimulatedPlayback    = False   # REAL path, not the silent clock
position after ~2 s                = 1.98 s  # advances in real time
StopAsync                          = State=Stopped
```
BASS decodes and plays on this host. The initial `IsAvailable=False` is a lazy
init artifact (`PlaybackQueueCoordinator.cs:400`), not a regression.

### B.4 Theme swap
Selecting the light `ThemeOption` applied the light token set and rendered
correctly (`37-light-quickplay`, `38-light-settings-general`). Dark restored.

### B.5 Navigation
All 8 top-level pivots, 8 Collection sub-pivots, 3 Now-Playing modes, all 13
software + 4 device Settings pages, and both wizards rendered without a single
capture failure (**44/44**).

`docs/disassembly/zune_uix_analysis.md`).
